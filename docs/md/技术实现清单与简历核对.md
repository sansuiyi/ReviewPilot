## 一、仓库性质

- 仓库名：`sansuiyi/ReviewPilot`，上游基线为 PR-Agent（Qodo Merge / the-pr-agent）。
- 在上游基线之上，`pr_agent/agent_exec/` 是 **ReviewPilot 自研的多阶段审查 Agent 框架**，含 OODA 循环、Jev 决策、Trajectory、Step/Tool Budget、Loop Detection、工具白名单、MCP 描述与外部工具适配、多 Sub-agent 扇出合并、Benchmark 评测框架。
- `/review` 命令通过 `[agent_exec].enabled` 门控，可在"原单次审查管线"与"有界 Agent 循环"之间切换，默认关闭，不破坏原管线。
